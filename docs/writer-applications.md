# ライター応募の審査

新規応募は、メールアドレスを確認済みのアカウントで受け付けます。受付にはユーザーIDと受付時点の確認済みメールアドレスが保存されます。メールアドレスを変更しても、受付に紐付いたアカウントが審査対象です。

編集長は管理画面で再認証し、応募カードのプロフィール、ユーザーID、受付時メールを確認して承認または見送りを確定します。アカウントと紐付いていない旧形式の応募を審査する際は、応募者にログインして再応募してもらってください。個別にロールを変更する場合は、ライター・ロール管理の一覧から対象アカウントを選びます。

応募受付後の運営者宛て連絡には既存の通知を使用します。応募が保存されると、DBが返した受付内容と確認済みメールアドレスで通知を試みます。
